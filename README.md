# SEN371 - Full-Stack E-Commerce Web Application

## Overview
A responsive, cross-platform e-commerce platform developed as part of the Software Engineering 371 (SEN371) module. This project follows an Agile development methodology with iterative sprints, Test-Driven Development (TDD), and an MVC architecture to ensure high maintainability, robust API security, and seamless user experience.

### Key Features & Architecture
- **Architecture:** Model-View-Controller (MVC) pattern with RESTful API integration.
- **Frontend:** Responsive, cross-platform UI designed in Figma and built for dynamic user interaction.
- **Backend & Database:** Scalable server-side API secured with JWT authentication and persistent data storage.
- **Quality & DevOps:** Automated testing via TDD (Red-Green-Refactor) and continuous deployment via GitHub Pages.
